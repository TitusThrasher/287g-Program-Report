# Report Changelog

## v2.0
Report changelog first published **September 15, 2026** ([website](https://www.tituslegaldesign.com/287g-program/report) / **November 01, 2026** (GitHub) with initial entry v2.0; previous report changes added retroactively under v1.X below.

- Change in 287(g) arrest dataset from total ICE arrests to new 'arrests with detention' dataset from Deportation Data Project;
- Schema change from ICE to add 'Apprehension city' (processed and styled as 'Arrest city' in this report), report arrest section expanded to add city-level analysis (with caveats re: ICE data quality).
- Canceled Agreements list backfilled through January 20, 2025.

### v1.4

-  Report overview page now includes total number of local/state law enforcement agencies per state + state participation rate (%).

# Security Policy

## Reporting a Vulnerability

While we do not expect any user security vulnerabilities due to the nature of this project. However, if you believe there may be a security-related concern with any of the processed data published to this repository, the project documentation, or the resources shared in this project repository, please email <info@tituslegaldesign.com> with the relevant details, and we will respond as soon as possible to confirm your report and provide context on our review and any mitigating actions taken.

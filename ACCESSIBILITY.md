# Accessibility

Accessibility of all kinds is a priority for this project repository and the broader 287(g) Program Report. Reliable, quality data on the operations of a federal law enforcement agency — its partners in thousands of local and state agencies across the country — is in the interest of the public. Therefore, this project is committed to maintaining the data published as accessible as possible for individuals using assistive technology.

This document explains our accessibility commitment, how viewers and (eventually) contributors can help us uphold it, and how to report accessibility issues.

<hr>

## Priorities


- **Accessibility target:** Working toward [WCAG 2.2 Level AA](https://www.w3.org/TR/WCAG22). This target guides the work but is _not_ a claim of verified conformance.
- **Keyboard support** — every interactive element will be reachable and operable with a keyboard alone, with a visible focus indicator and a logical tab order.
- **Screen reader support** — content will use semantic HTML and a logical heading hierarchy so it can be navigated with VoiceOver, NVDA, JAWS, and similar tools.
- **Readable content** — we use plain language when possible, descriptive link text, sufficient color contrast, semantic lists, and meaningful alternative text.
- **Translations** — languages declare which language they are in code so assistive tech can pronounce them correctly.

## Reporting accessibility issues

If you run into an accessibility barrier, please let us know — we treat accessibility reports as valuable insight, not complaints.

A proper accessibility issue form will be published here shortly. In the meantime, please email info@tituslegaldesign.com with any accessibility-related issues you may experience. Thank you for your patience!

<hr>

## Known limitations

  - Older newsletter articles, 3rd-party resources referenced in this project, etc. may not yet meet every guideline (for example, images missing alternative text or non-descriptive link text).
  - Embedded third-party content (videos, external images) may not always include captions or transcripts.

## Feedback

Accessibility is an ongoing practice, not a one-time fix. If you have suggestions for improving this statement or our practices, please open an issue or a pull request. Thank you!

# Maxwell Commons Newsletter Archive

Archived copies of articles from [**Maxwell Commons**](https://maxwellcommons.substack.com), a newsletter by Andrew Thrasher + Titus Consulting on the U.S. immigration system, with heavy emphasis and ongoing reporting on ICE's 287(g) program, using the same data published in this repository.

> [!NOTE]
> Each article reflects the 287(g) program data available **as of the article's publication date**. Agreement counts, arrest figures, and other numbers have changed since then. For current figures, see the [interactive report](https://tituslegaldesign.com/287g-program/report) or the latest snapshots in [`data/`](/data).

> [!TIP]
> The files in the `Archive` column below are body-only HTML exports from Substack. GitHub shows `.html` files as source code, so please either download and view in a browser or click the `Title` link to read the article on Substack. **COMING SOON:** GitHub Pages article viewer.
